# Retail Taxonomy Operations Platform

Public assessment package for the Full Stack coding test (React + FastAPI + PostgreSQL 16).

## Stranger quick start (Docker)

```bash
git clone <this-repo>
cd Retail-Taxonomy
cp .env.example .env
make up
make seed
make test
```

UI: http://localhost:5173 · API: http://localhost:8000 · OpenAPI: http://localhost:8000/openapi.json
